Core Domain Analysis: Bassan.os
Executive Summary
After rigorous analysis of 53+ documentation artifacts (including the 174KB SRS v3.1, 54KB BRD v2.2, Domain Glossary, and supporting documents), I have identified three potential core domains that could represent the TRUE identity of this product.

The Problem with the Current Documentation
The documentation suffers from domain confusion. Evidence:

Symptom	Source
Product called "ERP", "CRM", "Operating System", and "SaaS Platform" interchangeably	SRS, README
25 functional requirement groups (FR-001 to FR-025)	SRS v3.1
22 business requirements	BRD v2.2
56+ user stories across 13 persona categories	SRS
76 database entities	SRS
AI Bots, Omnichannel, Subscription, White-labeling, Marketplace all labeled "Must Have"	SRS
This creates a product with no center of gravity.

Three Possible Core Domains
Domain Candidate 1: Business Process Orchestration
"A configurable workflow engine for B2B service organizations"

Definition
The core problem being solved is: how to move work through an organization with accountability, visibility, and traceability. Everything else (CRM, Finance, HR) is secondary data feeding the workflow engine.

Evidence FROM Documentation

Cons

Final Recommendation
Domain Candidate 1: Business Process Orchestration
Bassan.os is a configurable workflow orchestration platform for B2B service organizations, enabling work to flow through departments with accountability, visibility, and traceability.

Justification
It's what the BRD actually claims
The vision statement says "operating system for modern service-driven businesses" and "business control layer". A workflow engine IS an operating system. CRM and AI features are not.

It explains why 22 Business Requirements exist
Every single BR (BR-01 through BR-22) relates to governance, workflow, accountability, or visibility. NONE of them are about "AI lead capture" or "omnichannel messaging."

It provides architectural clarity

Core Domain: Workflow Engine (States, Transitions, Assignments, Evidence, SLAs)
Supporting Domains: Sales (Lead/Opportunity), Customer Support (Tickets), HR (Tasks), Finance (Invoices tied to workflows)
Generic Subdomains: AI Services, Messaging Channels, Subscription Billing
It reduces scope without losing value
The AI Bots and Omnichannel features become inputs to the workflow engine (they create Leads that enter workflows), not the core identity. This clarifies development priorities.

It creates defensible differentiation
There are 1000+ CRMs. There are few "configurable workflow engines for B2B service companies" that also handle cross-department accountability.

What This Means Going Forward
If you accept this recommendation:

What Stays Core	What Becomes Secondary

This does NOT mean deleting those features. It means they are built after the workflow core is solid, and they integrate with the workflow engine rather than existing as parallel systems.

Phase 1: Minimal Executable Core
Workflow Orchestration Engine
1. Phase 1 Objective
Build the smallest possible workflow engine that can move work through states with explicit ownership and accountability.

This is NOT an ERP. NOT a CRM. NOT an AI system.
This is a workflow state machine with task ownership.

Success Definition (One Sentence)
A user can define a workflow, start an instance, assign tasks, complete them with evidence, and see the full audit trail.

4. Core Use Cases (Max 5)
UC-01: Define a Workflow
Actor: Admin or Workflow Manager
Precondition: User is authenticated, has workflow:create permission

Flow:

User provides workflow name and description
User adds states (marking one as START, one+ as END)
User defines transitions between states
User marks which states require evidence
System validates (at least one START, one END, all states reachable)
System saves WorkflowDefinition as DRAFT
User activates the workflow (status = ACTIVE)
Postcondition: WorkflowDefinition exists and can be instantiated

UC-02: Start a Workflow Instance
Actor: Any authorized user
Precondition: WorkflowDefinition is ACTIVE

Flow:

User selects a WorkflowDefinition
User specifies the subject (type + ID)
System creates WorkflowInstance in initial state
System creates first Task(s) based on initial state
System assigns Task owner (manual or via rule)
Postcondition: WorkflowInstance is RUNNING with at least one Task

UC-03: Assign or Reassign a Task
Actor: Manager or Task Owner
Precondition: Task exists, is not COMPLETED or CANCELLED

Flow:

User selects an unassigned or owned Task
User chooses new owner (must be User in same Tenant)
System validates new owner has appropriate role
System updates Task.ownerId
System logs ownership change in audit trail
Postcondition: Task has new single owner, audit trail updated

UC-04: Complete a Task with Evidence
Actor: Task Owner
Precondition: User is the Task.ownerId, Task is IN_PROGRESS

Flow:

Owner marks task as complete
IF state requires evidence:
Owner uploads evidence (file, link, or note)
System validates evidence exists
System updates Task.status = COMPLETED
System logs completion with timestamp
IF Task is linked to WorkflowInstance:
System checks if transition is allowed
System moves WorkflowInstance to next state
System creates next Task(s) if any
Postcondition: Task is COMPLETED, evidence attached, workflow may advance

UC-05: View Workflow Progress & Audit Trail
Actor: Manager, Owner, or Admin
Precondition: User has permission to view the WorkflowInstance

Flow:

User opens WorkflowInstance details
System displays:
Current state
All Tasks (past and pending)
Task owners and completion status
Evidence attached to each task
Full state transition history (who, when, from→to)
User can drill into any Task for details
Postcondition: User has full visibility into who did what, when

5. Primary Risks
Risk	Impact	Likelihood	Mitigation
R1: Scope Creep — Temptation to add "just one more feature"	HIGH	HIGH	Ruthless adherence to IN SCOPE list. Defer everything else.
R2: Workflow Complexity — Users create invalid workflows (orphan states, loops)	MEDIUM	MEDIUM	Workflow validation on save. Reject invalid structures.
R3: Multi-Tenancy Leaks — Data bleeds across tenants	CRITICAL	LOW	Tenant check on EVERY query. Use Row-Level Security or CLS.
R4: Task Ownership Ambiguity — Multiple owners or no owner	HIGH	MEDIUM	Enforce EXACTLY ONE owner at database constraint level.
R5: Evidence Gaps — Tasks completed without required evidence	MEDIUM	MEDIUM	Block state transition if evidence is required but missing.
6. Exit Criteria (Phase 1 Complete When)
Phase 1 is COMPLETE when ALL of the following are true:

#	Criterion	Verification Method
1	A Tenant can be created with at least one User	Manual test
2	A WorkflowDefinition can be created with 3+ states and 2+ transitions	Manual test
3	A WorkflowInstance can be started from an active WorkflowDefinition	Manual test
4	A Task can be assigned to exactly one User	Unit test + constraint
5	A Task can be completed with evidence	Manual test
6	Completing a task advances the WorkflowInstance state	Integration test
7	Full audit trail shows who did what, when	Query verification
8	Tenant A cannot see Tenant B's data	Security test

import { Prisma } from '@prisma/client';
import { Injectable, Logger } from '@nestjs/common';
import { ClsService } from 'nestjs-cls';
/**
 * PrismaTenantExtension - Core Multi-Tenancy Enforcement
 * 
 * 🛡️ CRITICAL SECURITY COMPONENT
 * 
 * This extension automatically:
 * 1. INJECTS organizationId into WHERE clauses for tenant-scoped models
 * 2. INJECTS organizationId into CREATE data
 * 3. BLOCKS queries without tenant context (throws error)
 * 4. OVERWRITES any manual organizationId to prevent injection attacks
 * 5. LOGS all queries for security audit
 * 
 * @security NEVER modify without security review
 */
/**
 * GLOBAL MODELS - NOT tenant-scoped
 * 
 * These models can be accessed without tenant context.
 * They are system-wide and not tied to any specific organization.
 */
const GLOBAL_MODELS = [
  'Organization',     // Root entity - organizations themselves
  'Permission',       // System-wide permissions
  'SystemConfig',     // System configuration
  // NOTE: AuditLog could be global or tenant-scoped depending on requirements
];
/**
 * TENANT-SCOPED MODELS - MUST have organizationId
 * 
 * All queries to these models will be automatically filtered by organizationId.
 * User is included because each user belongs to exactly one organization.
 */
const TENANT_SCOPED_MODELS = [
  'User',             // ✅ Each user belongs to an organization
  'Role',             // ✅ Roles are per-organization
  'UserRole',         // ✅ User-Role mapping per organization
  'RefreshToken',     // ✅ Tokens are per-user, thus per-org
  'Lead',             // ✅ Sales leads per organization
  'Task',             // ✅ Tasks per organization
  // Future models:
  // 'Invoice',
  // 'Project', 
  // 'Ticket',
  // 'Employee',
  // 'Contact',
];
export interface TenantContext {
  orgId: string | null;
  userId: string | null;
}
/**
 * Injectable Prisma Tenant Extension
 * 
 * Uses ClsService directly for context retrieval.
 */
@Injectable()
export class PrismaTenantExtension {
  private readonly logger = new Logger(PrismaTenantExtension.name);
  constructor(private readonly clsService: ClsService) {}
  /**
   * Creates the Prisma extension for tenant isolation
   */
  create() {
    const clsService = this.clsService;
    const logger = this.logger;
    return Prisma.defineExtension({
      name: 'tenant-isolation-enforcer',
      query: {
        $allModels: {
          async $allOperations({ model, operation, args, query }) {
            const orgId = clsService.get('orgId');
            const userId = clsService.get('userId');
            // 🔍 AUDIT LOG: Track all database operations
            logger.debug(
              [QUERY] ${model}.${operation} | OrgId: ${orgId || 'NONE'} | UserId: ${userId || 'NONE'}
            );
            // ✅ Global models - No filtering required
            if (GLOBAL_MODELS.includes(model)) {
              logger.debug([GLOBAL] ${model} - Allowing without tenant filter);
              return query(args);
            }
            // 🚨 CRITICAL: Block tenant-scoped queries without context
            if (!orgId && TENANT_SCOPED_MODELS.includes(model)) {
              const errorMsg = TENANT_ISOLATION_VIOLATION: No tenant context for ${model}.${operation};
              logger.error(🚨 ${errorMsg});
              throw new Error(errorMsg);
            }
            // Initialize args if needed
            if (!args) {
              args = {} as typeof args;
            }
            // 🛡️ APPLY TENANT FILTERING
            if (orgId) {
              // For CREATE operations - inject organizationId
              if (operation === 'create') {
                if (!(args as any).data) {
                  (args as any).data = {};
                }
                
                // 🚫 OVERWRITE any manual organizationId (security)
                if ((args as any).data.organizationId && (args as any).data.organizationId !== orgId) {
                  logger.warn(
                    ⚠️ [SECURITY] Blocked organizationId injection attempt:  +
                    ${(args as any).data.organizationId} -> ${orgId}
                  );
                }
                
                (args as any).data.organizationId = orgId;
                logger.debug([CREATE] Injected organizationId: ${orgId});
              }
              // For createMany - inject into each record
              if (operation === 'createMany') {
                if ((args as any).data && Array.isArray((args as any).data)) {
                  (args as any).data = (args as any).data.map((item: any) => ({
                    ...item,
                    organizationId: orgId, // Overwrite any existing
                  }));
                  logger.debug([CREATE_MANY] Injected organizationId into ${(args as any).data.length} records);
                }
              }
              // For READ/UPDATE/DELETE operations - inject WHERE filter
              if (
                operation.includes('find') ||
                operation.includes('update') ||
                operation.includes('delete') ||
                operation === 'count' ||
                operation === 'aggregate'
              ) {
                if (!(args as any).where) {
                  (args as any).where = {};
                }
                (args as any).where.organizationId = orgId;
                logger.debug([FILTER] Added organizationId to WHERE: ${orgId});
              }
              // For upsert - handle both where and create
              if (operation === 'upsert') {
                if (!(args as any).where) {

            // 🔍 AUDIT: Log result count for monitoring
            if (Array.isArray(result)) {
              logger.debug([RESULT] ${model}.${operation} returned ${result.length} records);

 * 2. Sets CLS context for Prisma tenant extension

@Injectable()
export class TenantGuard implements CanActivate {
  private readonly logger = new Logger(TenantGuard.name);
  constructor(private readonly cls: ClsService) {}
  canActivate(context: ExecutionContext): boolean {
    const request = context.switchToHttp().getRequest();
    const user = request.user as { id: string; email: string; organizationId: string } | undefined;
    // 🚨 CRITICAL: Must have validated JWT with organizationId
    if (!user) {
      this.logger.error('🚨 SECURITY: No user in request - JwtAuthGuard did not run');
      throw new UnauthorizedException('Authentication required');
    }
    if (!user.organizationId) {
      this.logger.error(🚨 SECURITY: No organizationId in JWT for user ${user.id});
      throw new UnauthorizedException('Invalid token - no organization context');
    }
    // ✅ Set CLS context from VALIDATED user object
    this.cls.set('orgId', user.organizationId);
    this.cls.set('userId', user.id);
    // 🛡️ SANITIZE REQUEST: Remove any manual organizationId injection attempts
    this.sanitizeRequest(request);
    this.logger.debug(
      ✅ Tenant context set | Org: ${user.organizationId} | User: ${user.id}
    );
    return true;
  }
  /**
   * Remove any manual organizationId from request to prevent injection attacks
   */
  private sanitizeRequest(req: Request): void {
    // Sanitize query parameters
    if (req.query) {
      if (req.query.organizationId) {
        this.logger.warn(⚠️ BLOCKED: Manual organizationId in query: ${req.query.organizationId});
        delete req.query.organizationId;
      }
      if (req.query.orgId) {
        this.logger.warn(⚠️ BLOCKED: Manual orgId in query: ${req.query.orgId});
        delete req.query.orgId;
      }
      if (req.query.tenantId) {
        this.logger.warn(⚠️ BLOCKED: Manual tenantId in query: ${req.query.tenantId});
        delete req.query.tenantId;
      }
    }
    // Sanitize request body
    if (req.body && typeof req.body === 'object') {
      if (req.body.organizationId) {
        this.logger.warn(⚠️ BLOCKED: Manual organizationId in body: ${req.body.organizationId});
        delete req.body.organizationId;
      }
      if (req.body.orgId) {
        this.logger.warn(⚠️ BLOCKED: Manual orgId in body: ${req.body.orgId});
        delete req.body.orgId;
      }
      if (req.body.tenantId) {
        this.logger.warn(⚠️ BLOCKED: Manual tenantId in body: ${req.body.tenantId});
        delete req.body.tenantId;
      }
    }
    // Sanitize URL parameters
    if (req.params) {
      if (req.params.organizationId) {
        this.logger.warn(⚠️ BLOCKED: Manual organizationId in params: ${req.params.organizationId});
        delete req.params.organizationId;
      }
    }
  }

            // SECURITY POLICY: FAIL-CLOSED DEFAULT
            // ══════════════════════════════════════════════════════════════
            // ✅ GLOBAL MODELS - Explicit whitelist, allowed without orgId
            if (GLOBAL_MODELS.includes(model)) {
              logger.debug([GLOBAL] ${model} - Allowing without tenant filter);
              return query(args);
            }
            // 🚨 FAIL-CLOSED: ALL non-global models require tenant context
            if (!orgId) {
              const errorMsg = TENANT_ISOLATION_VIOLATION: No tenant context for ${model}.${operation}.  +
                Model is not in GLOBAL_MODELS whitelist.;
              logger.error(🚨 ${errorMsg});
              throw new Error(errorMsg);

            if (!args) {
              args = {} as typeof args;
            }

            // TENANT FILTERING - Only for models with direct organizationId
            // ══════════════════════════════════════════════════════════════
            // Skip organizationId injection for indirectly-scoped models
            // (they don't have the column, isolation is via relations)
            if (INDIRECTLY_SCOPED_MODELS.includes(model)) {
              logger.debug([INDIRECT] ${model} - Has orgId context, skipping direct injection);
              return query(args);
            }
            // 🛡️ APPLY TENANT FILTERING for directly-scoped models
            if (hasDirectOrgId(model)) {
              // ──────────────────────────────────────────────────────────────
              // CREATE OPERATIONS
              // ──────────────────────────────────────────────────────────────
              if (operation === 'create') {
                if (!(args as any).data) {
                  (args as any).data = {};
                }
                
                // 🚫 OVERWRITE any manual organizationId (security)
                if ((args as any).data.organizationId && (args as any).data.organizationId !== orgId) {
                  logger.warn(
                    ⚠️ [SECURITY] Blocked organizationId injection in CREATE:  +
                    ${(args as any).data.organizationId} -> ${orgId}
                  );
                }
                
                (args as any).data.organizationId = orgId;
                logger.debug([CREATE] Injected organizationId: ${orgId});
              }
              // For createMany - inject into each record
              if (operation === 'createMany') {
                if ((args as any).data && Array.isArray((args as any).data)) {
                  (args as any).data = (args as any).data.map((item: any) => ({
                    ...item,
                    organizationId: orgId, // Overwrite any existing
                  }));
                  logger.debug([CREATE_MANY] Injected organizationId into ${(args as any).data.length} records);
                }
              }
              // ──────────────────────────────────────────────────────────────
              // READ OPERATIONS - Add WHERE filter
              // ──────────────────────────────────────────────────────────────
              if (
                operation.includes('find') ||
                operation === 'count' ||
                operation === 'aggregate'
              ) {
                if (!(args as any).where) {
                  (args as any).where = {};
                }
                (args as any).where.organizationId = orgId;
                logger.debug([FILTER] Added organizationId to WHERE: ${orgId});
              }
              // ──────────────────────────────────────────────────────────────
              // UPDATE OPERATIONS - Filter + BLOCK organizationId mutation
              // ──────────────────────────────────────────────────────────────
              if (operation === 'update') {
                if (!(args as any).where) {
                  (args as any).where = {};
                }
                (args as any).where.organizationId = orgId;
                // 🚫 CRITICAL: Block organizationId mutation
                if ((args as any).data && (args as any).data.organizationId !== undefined) {
                  logger.warn(
                    ⚠️ [SECURITY] Blocked organizationId mutation in UPDATE:  +
                    Attempted to set ${(args as any).data.organizationId}
                  );
                  delete (args as any).data.organizationId;
                }
                logger.debug([UPDATE] Filtered by organizationId: ${orgId});
              }
              if (operation === 'updateMany') {
                if (!(args as any).where) {
                  (args as any).where = {};
                }
                (args as any).where.organizationId = orgId;
                // 🚫 CRITICAL: Block organizationId mutation in bulk updates
                if ((args as any).data && (args as any).data.organizationId !== undefined) {
                  logger.warn(
                    ⚠️ [SECURITY] Blocked organizationId mutation in UPDATE_MANY:  +
                    Attempted to set ${(args as any).data.organizationId}
                  );
                  delete (args as any).data.organizationId;
                }
                logger.debug([UPDATE_MANY] Filtered by organizationId: ${orgId});
              }
              // ──────────────────────────────────────────────────────────────
              // DELETE OPERATIONS
              // ──────────────────────────────────────────────────────────────
              if (operation.includes('delete')) {
                if (!(args as any).where) {
                  (args as any).where = {};
                }
                (args as any).where.organizationId = orgId;
                logger.debug([DELETE] Filtered by organizationId: ${orgId});
              }
              // ──────────────────────────────────────────────────────────────
              // UPSERT OPERATIONS
              // ──────────────────────────────────────────────────────────────
              if (operation === 'upsert') {
                if (!(args as any).where) {
                  (args as any).where = {};
                }
                (args as any).where.organizationId = orgId;
                
                if ((args as any).create) {
                  (args as any).create.organizationId = orgId;
                }
                if ((args as any).update) {
                  // 🚫 Block organizationId mutation in update part
                  delete (args as any).update.organizationId;
                }
                logger.debug([UPSERT] Applied tenant filter and injection);
              }
            } else {
              // Unknown model with orgId context - log warning but allow
              // This handles future models before they're categorized
              logger.warn(
                ⚠️ [UNCATEGORIZED] Model ${model} not in any scope list.  +
                Has orgId context - allowing but NOT filtering. ADD TO APPROPRIATE LIST!
              );
            }
            // Execute the query with modified args
            const result = await query(args);
            // 🔍 AUDIT: Log result count for monitoring
            if (Array.isArray(result)) {
              logger.debug([RESULT] ${model}.${operation} returned ${result.length} records);
            }
            return result;
          },
        },
      },
    });
  }

      ],
    });

   *

const INDIRECTLY_SCOPED_MODELS = [
  'Permission',       // Scoped via Role -> Organization (roleId required)
  'UserRole',         // Scoped via User -> Organization (userId required)
  'RefreshToken',     // Scoped via User -> Organization (userId required)
];
/**
 * MODELS WITH DIRECT organizationId FIELD
 * 
 * These models have organizationId column and get auto-filtering.
 */
const DIRECTLY_SCOPED_MODELS = [
  'User',
  'Role',
  'Lead',
  'Task',
];
export interface TenantContext {
  orgId: string | null;
  userId: string | null;
}
/**
 * Injectable Prisma Tenant Extension
 * 
 * Uses ClsService directly for context retrieval.
 */
@Injectable()
export class PrismaTenantExtension {
  private readonly logger = new Logger(PrismaTenantExtension.name);
  constructor(private readonly clsService: ClsService) {}
  /**
   * Check if model has direct organizationId field
   */
  private hasDirectOrgId(model: string): boolean {
    return DIRECTLY_SCOPED_MODELS.includes(model);
  }
  /**
   * Creates the Prisma extension for tenant isolation
   */
  create() {
    const clsService = this.clsService;
    const logger = this.logger;
    const hasDirectOrgId = this.hasDirectOrgId.bind(this);
    return Prisma.defineExtension({
      name: 'tenant-isolation-enforcer',
      query: {
        $allModels: {
          async $allOperations({ model, operation, args, query }) {
            const orgId = clsService.get('orgId');
            const userId = clsService.get('userId');
            // 🔍 AUDIT LOG: Track all database operations
            logger.debug(
              [QUERY] ${model}.${operation} | OrgId: ${orgId || 'NONE'} | UserId: ${userId || 'NONE'}
            );
            // ══════════════════════════════════════════════════════════════
            // SECURITY POLICY: FAIL-CLOSED DEFAULT
            // ══════════════════════════════════════════════════════════════
            // ✅ GLOBAL MODELS - Explicit whitelist, allowed without orgId
            if (GLOBAL_MODELS.includes(model)) {
              logger.debug([GLOBAL] ${model} - Allowing without tenant filter);
              return query(args);
            }
            // 🚨 FAIL-CLOSED: ALL non-global models require tenant context
            if (!orgId) {
              const errorMsg = TENANT_ISOLATION_VIOLATION: No tenant context for ${model}.${operation}.  +
                Model is not in GLOBAL_MODELS whitelist.;
              logger.error(🚨 ${errorMsg});
              throw new Error(errorMsg);
            }
            // Initialize args if needed
            if (!args) {
              args = {} as typeof args;
            }
            // ══════════════════════════════════════════════════════════════
            // TENANT FILTERING - Only for models with direct organizationId
            // ══════════════════════════════════════════════════════════════
            // Skip organizationId injection for indirectly-scoped models
            // (they don't have the column, isolation is via relations)
            if (INDIRECTLY_SCOPED_MODELS.includes(model)) {
              logger.debug([INDIRECT] ${model} - Has orgId context, skipping direct injection);
              return query(args);
            }
            // 🛡️ APPLY TENANT FILTERING for directly-scoped models
            if (hasDirectOrgId(model)) {
              // ──────────────────────────────────────────────────────────────
              // CREATE OPERATIONS
              // ──────────────────────────────────────────────────────────────
              if (operation === 'create') {
                if (!(args as any).data) {
                  (args as any).data = {};
                }
                
                // 🚫 OVERWRITE any manual organizationId (security)
                if ((args as any).data.organizationId && (args as any).data.organizationId !== orgId) {
                  logger.warn(
                    ⚠️ [SECURITY] Blocked organizationId injection in CREATE:  +
                    ${(args as any).data.organizationId} -> ${orgId}
                  );
                }
                
                (args as any).data.organizationId = orgId;
                logger.debug([CREATE] Injected organizationId: ${orgId});
              }
              // For createMany - inject into each record
              if (operation === 'createMany') {
                if ((args as any).data && Array.isArray((args as any).data)) {
                  (args as any).data = (args as any).data.map((item: any) => ({
                    ...item,
                    organizationId: orgId, // Overwrite any existing
                  }));
                  logger.debug([CREATE_MANY] Injected organizationId into ${(args as any).data.length} records);
                }
              }
              // ──────────────────────────────────────────────────────────────
              // READ OPERATIONS - Add WHERE filter
              // ──────────────────────────────────────────────────────────────
              if (
                operation.includes('find') ||
                operation === 'count' ||
                operation === 'aggregate'
              ) {
                if (!(args as any).where) {
                  (args as any).where = {};
                }
                (args as any).where.organizationId = orgId;
                logger.debug([FILTER] Added organizationId to WHERE: ${orgId});
              }
              // ──────────────────────────────────────────────────────────────
              // UPDATE OPERATIONS - Filter + BLOCK organizationId mutation
              // ──────────────────────────────────────────────────────────────
              if (operation === 'update') {
                if (!(args as any).where) {
                  (args as any).where = {};
                }
                (args as any).where.organizationId = orgId;
                // 🚫 CRITICAL: Block organizationId mutation
                if ((args as any).data && (args as any).data.organizationId !== undefined) {
                  logger.warn(
                    ⚠️ [SECURITY] Blocked organizationId mutation in UPDATE:  +
                    Attempted to set ${(args as any).data.organizationId}
                  );
                  delete (args as any).data.organizationId;
                }
                logger.debug([UPDATE] Filtered by organizationId: ${orgId});
              }
              if (operation === 'updateMany') {
                if (!(args as any).where) {
                  (args as any).where = {};
                }
                (args as any).where.organizationId = orgId;
                // 🚫 CRITICAL: Block organizationId mutation in bulk updates
                if ((args as any).data && (args as any).data.organizationId !== undefined) {
                  logger.warn(
                    ⚠️ [SECURITY] Blocked organizationId mutation in UPDATE_MANY:  +
                    Attempted to set ${(args as any).data.organizationId}
                  );
                  delete (args as any).data.organizationId;
                }
                logger.debug([UPDATE_MANY] Filtered by organizationId: ${orgId});
              }
              // ──────────────────────────────────────────────────────────────
              // DELETE OPERATIONS
              // ──────────────────────────────────────────────────────────────
              if (operation.includes('delete')) {
                if (!(args as any).where) {
                  (args as any).where = {};
                }
                (args as any).where.organizationId = orgId;
                logger.debug([DELETE] Filtered by organizationId: ${orgId});
              }
              // ──────────────────────────────────────────────────────────────
              // UPSERT OPERATIONS
              // ──────────────────────────────────────────────────────────────
              if (operation === 'upsert') {
                if (!(args as any).where) {
                  (args as any).where = {};
                }
                (args as any).where.organizationId = orgId;
                
                if ((args as any).create) {
                  (args as any).create.organizationId = orgId;
                }
                if ((args as any).update) {
                  // 🚫 Block organizationId mutation in update part
                  delete (args as any).update.organizationId;
                }
                logger.debug([UPSERT] Applied tenant filter and injection);
              }
            } else {
              // 🚨 FAIL-CLOSED: Unknown/uncategorized models are BLOCKED
              // This prevents security gaps when new models are added without proper categorization
              const errorMsg = TENANT_ISOLATION_VIOLATION: Model '${model}' is not categorized for tenant enforcement.  +
                Add to GLOBAL_MODELS, DIRECTLY_SCOPED_MODELS, or INDIRECTLY_SCOPED_MODELS.;
              logger.error(🚨 ${errorMsg});
              throw new Error(errorMsg);
            }
            // Execute the query with modified args
            const result = await query(args);
            // 🔍 AUDIT: Log result count for monitoring
            if (Array.isArray(result)) {
              logger.debug([RESULT] ${model}.${operation} returned ${result.length} records);
            }
            return result;
          },
        },
      },
    });
  }
}
