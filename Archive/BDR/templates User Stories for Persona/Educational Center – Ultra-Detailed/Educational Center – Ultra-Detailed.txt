Educational Center – User Stories
1️⃣ Director / Owner – Hany Fathy
#	User Story	Acceptance Criteria	Priority	Module / Feature
1	As a Director, I want to view a real-time dashboard of all students, teachers, and classes, so that I can monitor performance and resource allocation instantly.	Dashboard shows current student attendance, teacher availability, active classes, and key KPIs; updates in real-time; exportable reports.	High	Analytics / Operations
2	As a Director, I want to receive automatic alerts for delayed payments or inactive students, so that I can take timely action.	Alerts trigger when payments are overdue or student is absent > 3 consecutive classes; notifications via email, WhatsApp, Telegram, and dashboard.	High	Finance / Notifications
3	As a Director, I want to assign special tasks to Department Heads remotely, so that operations continue without manual intervention.	Task assignment reflects in Department Heads' dashboards; includes deadlines and priority; track completion.	High	Operations / HR
4	As a Director, I want to generate weekly and monthly reports for student performance and teacher evaluations, so that I can make strategic decisions.	Reports include attendance, grades, teacher performance; downloadable PDF/Excel; graphs for trends.	Medium	Analytics / Reporting
5	As a Director, I want to review resource utilization (classrooms, equipment), so that I can optimize allocation and reduce costs.	Visual representation of classrooms and resources usage; alerts for conflicts or overbooking.	Medium	Operations / Analytics
2️⃣ Academic Head / Department Head – Dr. Laila Samir
#	User Story	Acceptance Criteria	Priority	Module / Feature
1	As an Academic Head, I want to create and adjust course schedules for multiple classes, so that teachers and students are properly allocated.	Schedule editor supports drag-and-drop, auto-conflict detection, and live updates to all stakeholders.	High	Operations / Scheduling
2	As an Academic Head, I want to track teacher attendance and student participation, so that I can identify gaps and improve learning.	Attendance dashboard displays per-class and per-teacher metrics; alerts for irregularities; exportable.	High	Analytics / Operations
3	As an Academic Head, I want to assign tasks to teachers for exams, assignments, or extra sessions, so that responsibilities are clear and trackable.	Tasks assigned with deadlines, priority, and linked to classes; status updates visible to Head.	High	Operations / Task Management
4	As an Academic Head, I want to review performance trends for students, so that I can identify top performers and those needing support.	Reports show grade trends, attendance patterns, flagged students; supports filtering by class, grade, or period.	Medium	Analytics / Reporting
5	As an Academic Head, I want to coordinate with Reception for student registration updates, so that student data is accurate and complete.	Student list automatically updates with new registrations; changes visible in scheduling and reporting modules.	Medium	CRM / Operations
