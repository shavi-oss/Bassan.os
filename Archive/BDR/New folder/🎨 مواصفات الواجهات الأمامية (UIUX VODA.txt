📏 **نظام 8px:**

• 16px (md)
• 24px (lg)
• 32px (xl)
• 48px (xxl)

📏 **الهوامش (Containers):**
• هوامش الصفحة: 24px

3. الظلال والتأثيرات (Shadows & Effects):
text
🌑 **الظلال:**

• ظل متوسط: 0 4px 8px rgba(0, 0, 0, 0.15)
• ظل قوي: 0 8px 16px rgba(0, 0, 0, 0.2)

✨ **التأثيرات:**
