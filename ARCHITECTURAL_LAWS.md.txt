2. ABSOLUTE FILE SYSTEM LAWS
LAW FS-01 — Test Placement (ABSOLUTE)

RULE
No test file may exist under src/**.

FORBIDDEN

src/**/*.spec.ts
src/**/*.e2e.ts
src/**/*test*.ts


ALLOWED (ONLY)

tests/**


ENFORCEMENT

Security linter scans repository

If any forbidden path is detected → BUILD FAIL

LAW FS-02 — Security Linter Singularity

RULE
There must be exactly ONE security linter.

REQUIRED LOCATION

tests/security/security-linter.spec.ts


FORBIDDEN

src/security/**
any duplicate linter file


ENFORCEMENT

Linter verifies its own singularity

6. MULTI-TENANCY DOCTRINE (FINAL & INTENTIONAL)
LAW MT-01 — Isolation Strategy (FINAL)

The system uses a DUAL BUT INTENTIONAL ISOLATION MODEL:

CLS-based isolation

For root entities

Entities contain organizationId

Relation-based isolation

For indirect entities

Entities DO NOT contain organizationId

Access enforced via parent relation

Parent–Child Implicit Filtering

Child entities inherit tenant scope from parent

No duplication of organizationId

THIS IS NOT TRANSITIONAL.
THIS IS NOT OPTIONAL.
THIS IS NOT SUBJECT TO CHANGE WITHOUT OVERRIDE.

ENFORCEMENT

Linter rules MT-L*
